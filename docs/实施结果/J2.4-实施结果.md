## 1. 做了什么

把 `legacy/monolith.js` 里**门窗开合 / 抽屉滑动**的公共运动实现提取为独立模块：

| 项 | 内容 |
|---|---|
| 新增 | `src/cabin/core/util/spring.js`（113 行，导出 `createSpringSystem()`） |
| 改动 | `src/cabin/legacy/monolith.js` **2 处**：① 顶部加一条 import；② 原 382–385 行（4 行压缩写法）→ 1 行解构 |
| 迁移量 | 原 4 行（其中 `updateSprings` 单行 900+ 字符）→ 模块内 113 行 |
| 语义 | **零改动**：系数（0.015/0.95 铰链、0.02/0.92 滑轨）、更新顺序、公式逐字照搬；仅把单行压缩写法重新排版为多行 |

**为什么保留原标识符名**：monolith 文件内 `registerHinge` / `regSlide` / `hingeMeshes` /
`updateSprings` 共 9 处调用点（L410、L426、L2550、L4799、L4879、L4899、L5050、L7464、L7512、L8064）
**一行都不用改** —— 解构让搬迁的爆炸半径收敛为"文件头 + 一处定义"。

**为什么是工厂而不是模块级单例**：
`hingeMeshes` 是准星射线（`aimRay`）与点击射线（`pointerup`）的**唯一命中集合**，
monolith 直接引用它；集合的生命周期也跟"一局"绑定。工厂把持有权交回调用方，
同时满足不变量 `N7`（禁止新增全局可变状态）。

## 3. ★ 本次同时做的两处判据维护（必须记录）

J2 是**第一个真正改动 `src/cabin/**` 的阶段**（J1.5 的 DoD 是"一行未改"）。
两处为 J1.5 及更早设计的安全网因此**必然变红** —— 这不是回归，是判据的适用范围到了尽头。
按「偏差留痕」原则，两处都**改判据本身并写明原因**，而不是绕过：

### 3.1 `verify-f06` 的「撤销 J0.6 → 与 F0.4 快照一致」

- **它守什么**：`J0.6` 当时只加了渲染统计钩子、没夹带别的改动。
- **为什么不成立**：撤销 J0.6 后得到的是「F0.4 + J2 的搬迁」，与 F0.4 快照当然不再一致。
- **处理**：判据降级为**参考项**（打印差异首位置，不计入失败），判据是
  「文件里出现对 `cabin/core/**` 或 `cabin/systems/**` 的 import ⇒ 已进搬迁期」。
  注释写清"这不是放宽阈值"：该事实在 `J0.6` 收尾时已被验过；`monolith` 被 `J4` 删除后本脚本退役。
  **其余 39 项性能基线断言不受影响**，仍是 `J2`–`J4` 的性能护栏。

### 3.2 `tests/baseline/cabin-digest.json` 摘要基线重录

- **它守什么**：J1.5 期间"站点那一半没碰 3D 那一半"（当时本项目还不是 git 仓库，
  用逐字节摘要代替 `git diff` 为空）。
- **为什么不成立**：J2 起每个任务都会合法改变 `src/cabin/**`。
- **处理**：重录为 **11 个文件 / 10054 行**（新增 `core/util/spring.js`），
  并把 `what` / `why` / `note` 三个字段改写为**搬迁期语义**：
  它从"J1.5 一行未改"的判据，转为**3D 源码指纹**（防意外改动）。
- **新节奏**（后续每个 J2 任务照此办理）：任务内本项变红属**预期** →
  在结果文档记一笔原因 → 收尾前 `node scripts/verify-j15.mjs --record`。

## 5. 遗留与交接

| 项 | 留给谁 | 说明 |
|---|---|---|
| `updateSprings()` 的调用档位 | `J2.5` | 现仍在 `tickOnce()` 里按原顺序内联调用（L8064）。`UpdateScheduler` 建好后以 `always` 档注册，**顺序必须保持原位**（否则画面会变） |
| `hinges` / `slides` 集合的持有权 | `J4` | 现在由 monolith 解构持有；`J4` 搬 `player`/`ui` 时随物件一起收口到 `app/` |
| `userData.spring` / `userData.slide` 的契约 | `J3` | 已固定为字段契约（`base`/`delta`/`bounce`/`sfx`/`aimLabel`/`onToggle`），`defineProp` 的 `state()` 需按此产出 |
