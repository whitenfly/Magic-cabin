## 1. 病根

`cbRun` 是这一件**唯一**的状态量，却被**区间外**读：

```js
ptCb += ((cbRun > 0 ? 1 : 0) - ptCb) * 0.055;   // 「室内点光源」5 行之一
```

而 `ptCb` 是光照场第 5 个注册（槽位 4）的强度输入 ⇒ `J3` 判定搬走与重注册**两条路都破判据**。

### 2.1 帧顺序：`ptCb` 的平滑提前，为什么等价

几何分支在 `frame/25`、强度平滑在 `frame/95`（`lightField.update` 是 `frame/97`）⇒ 取**几何分支的位置**（早）。
两条论证同 `hangingLantern.js`：① 一阶低通，同帧同 `dt` 同输入 ⇒ 逐位相同，
`grep cbRun` 的全部命中只有本物件（外加 `frame/97` 才调用的 `lights()` 闭包）⇒ 两位置之间无读者/写者；
② 本 `update` 在 `frame/25`，远早于 `frame/97`。
