## 2. ★ `J4.32` §3.5 列的"仍需三件事"，逐条处置

### 2.1 `clock.now` → `s.now`

**只有一处**：L749（`regMagic` 回调里 `wandState.t0 = clock.now`）
⇒ 改 `s.t0 = s.now`，其中 `update` 第一行写 `s.now = time`
—— 与 `floor2/rubik.js` / `floor2/magicBook.js` / `floor2/board.js` 同法（事件在两帧之间执行 ⇒ 恒等）。

### 2.2 `runtimeRng` 的**次数与顺序**

**本段共 9 处 `runtimeRng()`，全部在运行期**（点击施法那一刻）：

| 位置 | 次数 | 何时 |
|---|---|---|
| L479（`buildCreation` 内 `e.userData.rd`）| 1 | 点击时 |
| L645 / L646 / L648（`genBolt` 的球坐标）| 3 | 点击时 |
| L655 / L656 / L657（`genBolt` 的三轴抖动，在循环里）| 3×（每点一次）| 点击时 |
| L746（`regMagic` 里抽元素）| 1 | 点击时 |

⇒ **`build` 期一次都不消耗** ⇒ **装配位置对 `runtimeRng` 序列没有约束**；
但**点击后的调用顺序必须逐字保持**（`idx` 先抽、再 `buildCreation`、再 `buildMagicCircle`…）。

### 2.3 `scene.add` / `scene.remove` 的动态增删顺序

| 处 | 时机 | 对象 |
|---|---|---|
| L276 · L279 · L284 | **`build` 期** | `hook` · `outline` · `wandG` ⇒ **顺序敏感，必须留在原位** |
| L800 · L804 | **运行期**（施法）| `s.circleHolder` · `s.crea` ⇒ 动态加入 |
| L754 · L759 | **运行期**（`clearCast`）| 同上，动态移除 |

⇒ `build` 期的三处由「`build` 内部自己 `scene.add`」这条纪律覆盖（`N` 条搬迁纪律之一）；
运行期的四处**保持逐字**（`scene.add` / `scene.remove` 的调用点不要挪）。

```powershell
Select-String -Path 'src\cabin\**\*.js' -Pattern "ctx\.$k\b"   # ❌ 全部 0 命中（假阴性！）
```
