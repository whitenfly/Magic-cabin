## 0. 一句话结论

长餐桌旁的 **5 把可推拉椅子**升格为 `world/floor1/diningChairs.js`：几何 + **5 条交互**
（每把一条）+ 每帧分支。

画面 **3/3 机位 sha256 逐字节相同**；页面诊断 0 错误；探针 7/7
（`props=45`、`interactables=99` = 原 94 + 5）。

> ★ **为什么它可以与茶壶分开搬**：`SKIP` 说这一带是"互相咬合的三块"，
> 但那三块的**咬合点是 `cups` / `makeCup`**（茶壶读 `cups[2]`、暖桌摆两只）。
> **椅子与茶壶没有共享状态** —— 它的状态全在自己的 `g.userData` 里。
> ⇒ 唯一交集是"都在长餐桌一带"，**不是依赖**。

本件**不消耗 `rng`**。

**5 条 `label` 按方位语义化**（而不是"第 N 把"）：左后 / 中后 / 右后 / 左侧 / 右侧，
锚点全部与 `makeChair(...)` 的落点**同源**（`L.DT_X + dx` / `L.DT_Z + dz`，不变量 `N9`）。
