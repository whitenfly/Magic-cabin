## 与 `world/**` 的分工

| | `cabin/world/**` | `cabin/props/**`（本目录） |
|---|---|---|
| 职责 | **摆放**：位置、朝向、所属楼层、挂载点 | **造型**：几何与材质工厂 |
| 状态 | 场景实例的状态（开/关、抽出/推回） | **无状态** —— 工厂函数，返回新的 `Group` |
| 被谁用 | 场景装配 | `world/**` 的 `build()` 里调用 |

```js
// props/teapot.js —— 无状态工厂
export function makeTeapot({ color = 0x8d6e63 } = {}) { /* … 返回 THREE.Group … */ }

// world/floor1/longTable.js —— 摆放者
import { makeTeapot } from '@/cabin/props/teapot'
put(makeTeapot(), 0.3, top, -0.1, 0, 0, 0, tableG)
```

## 两条约束

1. **`props/` 不注册交互、不注册光源** —— 那是摆放者（`world/**` 的 `defineProp`）的职责。
   工厂只负责"长什么样"。
2. **搬进本目录的唯一理由是"真的重复"**（≥2 处）。
   只出现一次的道具留在自己的 `world/**` 文件里，不要为了"看起来整齐"而抽出来 ——
   那会让单件搬迁变成跨文件改动，破坏"一个物件一次提交"的规矩。
